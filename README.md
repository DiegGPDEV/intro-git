# Mi primer repositorio

En este miniproyecto he aprendido los siguientes comandos:

- `git colne`
- `git log`, con los modificadores `--oneline` y `--all`
- `git checkout`
- `git add .`
- `git commit -m "mensaje"`
- `git remote`, invluyendo `get-url` y `set-url`
- `git diff`
- `git merge`, para arrelar una cosita
- `git push`
